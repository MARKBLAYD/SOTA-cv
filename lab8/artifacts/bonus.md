# Бонусное мини-исследование: батч-разнообразие uncertainty-запроса

**Гипотеза.** Чистый entropy-запрос собирает батч из похожих объектов одного предсказанного класса; польза их меток дублируется. Ограничение не более 1 объекта на предсказанный класс в батче должно увеличить AUC.

**Протокол.** load_digits, тот же initial/test/бюджет, что в основном эксперименте; сравнение random / entropy / entropy_diverse (лимит по предсказанному классу); 3 сида для diverse; отложенный test используется только для измерения, гипотеза по нему не подбиралась.

**Наблюдения.** AUC: random=0.8795, entropy=0.8448, entropy_diverse=0.8624±0.0000 (по сидам: [0.8624, 0.8624, 0.8624]). Итоговая accuracy: {'random': {'auc': 0.8795, 'final_acc': 0.913}, 'entropy': {'auc': 0.8448, 'final_acc': 0.8981}, 'entropy_diverse': {'auc': 0.8624, 'final_acc': 0.9093}}.

**Вывод.** Гипотеза подтверждена (ΔAUC vs entropy = +0.0176). entropy действительно сгущает батч в 1-2 кластерах; лимит по классу добавил разнообразие.
